# Student Registration System - Swing GUI Preview

This project contains manual Java Swing screens connected to the Student Registration System Spring Boot API at `http://localhost:8080/api`.

The screens use the original backend's entities and fields as their guide, while the visual layout follows the supplied group-member frontend: dark header, light background, white content cards, blue action buttons, dashboards, tables and forms.

## Run in IntelliJ IDEA

1. Open this folder as a Maven project.
2. Open `StudentRegistrationSystemFrontend.java`.
3. Run its `main` method.
4. Start the backend before opening application, tracking, or login screens.
5. Login is intentionally static: enter a recognised email and any non-empty password.

The frontend uses only Java Swing and Java's built-in `HttpClient`. It has no JavaFX, DTO, record, Jackson, or other frontend dependency.

Users do not type IDs into create forms. IDs, lecturer numbers, student numbers and student email addresses are generated by the system.

The fixed administrator email is `admin@cput.ac.za`. Students use the generated student email and lecturers use their stored lecturer email.

## Included preview screens

- Login
- Administrator dashboard
- Applicant management and applicant form
- Application management
- Student management and student form
- Lecturer management and lecturer form
- Department management and department form
- Course management and course form
- Class management and class form
- Registration management and registration form

Applicant submission, three course applications, the random application result, generated student record, application tracking and email-based dashboard routing use the backend. Some remaining management screens still retain preview data until their individual CRUD clients are connected.

## Layout notes

- Windows automatically fit within the usable desktop area.
- Long applicant and lecturer forms scroll vertically instead of clipping fields.
- Tables, buttons, fields, cards and headers share one consistent visual style.
- The original screen flow and preview-only behaviour have been preserved.
